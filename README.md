Headline: Built a Speaker Recognition System using Python & Machine Learning

Description:
I'm excited to share my latest project: a Speaker Recognition System that identifies individuals from short audio clips with high accuracy!

Technical Stack:
   Audio Processing: Librosa & Soundfile (MFCC feature extraction)
   Machine Learning: Scikit-Learn (Support Vector Machine - SVM)
   Data Analysis: Pandas & NumPy
   Visualization: Matplotlib & Seaborn

How it works:
1.  Feature Extraction: Processed raw `.wav` files to extract Mel-Frequency Cepstral Coefficients (MFCCs), capturing the unique spectral characteristics of each voice.
2.  Model Training: Trained a Linear SVM classifier on the VoxCeleb dataset to map voice patterns to specific speaker IDs.
3.  Real-time Inference: Developed a prediction pipeline that can identify a speaker from a new audio file with a confidence score.

Results:
Achieved an impressive 97% accuracy on the test set across multiple speakers! This project demonstrates the power of signal processing combined with traditional ML classifiers for biometric identification.
